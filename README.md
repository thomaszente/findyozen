# Find Yo Zen

A wellness discovery app for Austin with an interactive Zen master, the Zen Den (seven practice rooms), chakra frequencies and curated local spots.

Static site: no build step. Deploys on Vercel as-is.

## Versions
Each version is a git tag (`v0.3`, `v0.4`, …). Experiments live on branches, and every branch gets its own Vercel preview link.
